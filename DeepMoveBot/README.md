# DeepMoveBot

Тестовый шахматный бот DeepMove: собственный математический поиск и оценка позиции, без нейросети, обученных весов, Stockfish, дебютной книги и внешнего сервиса. Это отдельный переносимый Python-пакет; сервер арены менять не нужно.

Библиотека `chess` 1.11.2 используется для правил, легальных ходов и FEN/PGN. Поиск и оценка находятся в этом каталоге и написаны самостоятельно. Сила игры не измерена в Elo: это прозрачный учебный движок для тестирования платформы.

## Установка

Из корня репозитория, PowerShell:

```powershell
cd DeepMoveBot
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

Python 3.10+. Активировать виртуальное окружение необязательно. На Linux/macOS замените `.\.venv\Scripts\python.exe` на `.venv/bin/python`. Каталог можно перенести в отдельный репозиторий и установить той же командой. Серверу арены установка Python-пакета не нужна.

## Играть на арене

Создайте аккаунт и партию на `/arena`, выберите своё место «Бот», пригласите соперника, выпустите ключ. Затем:

```powershell
.\.venv\Scripts\python.exe -m deepmove_bot play --game GAME_UUID --side w
```

Ключ вводится скрыто. По умолчанию сервер — `http://127.0.0.1:3000`, на поиск выделяется до 1,8 секунды, а сетевой запас — 300 мс плюс измеренный RTT. Снимок сервера всегда ограничивает доступное время, независимо от CLI-настроек.

Пример с меньшим временем, фиксированным seed и отключённой случайностью:

```powershell
.\.venv\Scripts\python.exe -m deepmove_bot play --url http://127.0.0.1:3000 --game GAME_UUID --side b --max-think 1.0 --reserve 0.5 --noise 0 --seed 42
```

Секрет также можно передать процессу в переменной `DEEPMOVE_BOT_TOKEN`. Не используйте ключ в аргументах, URL, исходниках или PGN. В удалённом режиме обязателен HTTPS.

## Разобрать позицию офлайн

```powershell
.\.venv\Scripts\python.exe -m deepmove_bot analyze --time 1 --depth 5 --seed 42
.\.venv\Scripts\python.exe -m deepmove_bot analyze --fen "6k1/5ppp/8/8/8/8/5PPP/3R2K1 w - - 0 1" --time 1 --noise 0
.\.venv\Scripts\python.exe -m deepmove_bot analyze --pgn game.pgn --time 2
```

JSON содержит ход UCI, оценку со стороны хода, завершённую глубину, узлы, длительность, PV, кандидатов и разложение статической оценки. Значения около ±30000 — матовые, не обычные cp. При `depth=0` сработал легальный fallback, потому что целая итерация не успела завершиться. Терминальная позиция возвращает `move: null`.

## Как он играет

- Итеративное углубление и negamax с alpha-beta отсечениями.
- Quiescence: продолжение взятий/превращений, все уходы от шаха, без stand-pat под шахом.
- Таблица транспозиций с учётом истории, MVV-LVA, killer/history ordering.
- Ручная MG/EG-оценка: материал, центр/развитие, подвижность, пешки, пара слонов, открытые файлы, безопасность короля.
- Выбор максимум из трёх ходов в пределах 20 cp от лучшего по softmax. При явном мате случайность отключена.
- Восстановление полной истории партии: повторение нельзя корректно определить только по FEN.

Все коэффициенты, ограничения и формулы: [docs/FORMULAS.md](docs/FORMULAS.md).

## Коннектор как пример для участников

[docs/CONNECTOR.md](docs/CONNECTOR.md) описывает ready/move, UCI/FEN/PGN, `expectedPly`, дедлайны, потерянные ответы и отзыв ключей. Минимальный runnable-пример собственного алгоритма:

```powershell
.\.venv\Scripts\python.exe examples/custom_algorithm.py --game GAME_UUID --side w
```

Модуль `connector.py` не зависит от математического движка: можно оставить транспорт и заменить функцию `choose_move(Turn) -> str`. Основной движок также можно вызывать напрямую через `Engine.search(board, seconds)` без сети.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m deepmove_bot bench --games 4 --time 0.15 --max-plies 120 --opponent greedy --seed 42 --out reports/vs-greedy.pgn
```

Бенчмарк меняет цвета, сохраняет настоящие PGN и отдельно считает незавершённые партии: предел полуходов не выдаётся за ничью. `greedy` — один полуход собственной статической оценки, `random` — случайный легальный ход. Это проверки против простых соперников, не рейтинг Elo.

Проверка двух настоящих процессов бота на production-сборке арены:

```powershell
# Сначала из корня родительского репозитория: npm ci; npm run build
node scripts/arena-smoke.mjs
```

Скрипт сам поднимает отдельный сервер на порту 3117 и отдельную базу в `reports/`, создаёт тестовые аккаунты, запускает два DeepMoveBot с обычным max-think=1,8 с в режиме 10 минут / максимум 3 с, проверяет 12 принятых полуходов и заканчивает тест явной сдачей. Сервер и боты останавливаются автоматически; пользовательская база не меняется. Можно указать другой Python через `DEEPMOVE_BOT_PYTHON`.

Результаты фактически выполненной проверки: [docs/VALIDATION.md](docs/VALIDATION.md). Локальные временные базы и отчёты в `reports/` не коммитятся.

## Структура и ограничения

```text
src/deepmove_bot/evaluation.py  ручная оценка и её разложение
src/deepmove_bot/search.py      поиск, кэш, контроль времени, softmax
src/deepmove_bot/connector.py   HTTP и проверка снимков арены
src/deepmove_bot/bot.py         распределение времени и адаптер
src/deepmove_bot/cli.py         play / analyze / bench
examples/custom_algorithm.py   короткий пример своего алгоритма
tests/                         тесты правил, поиска, времени и транспорта
scripts/arena-smoke.mjs         интеграция с настоящей ареной
```

Python выбран ради читаемости и переносимости. За фиксированное время глубина зависит от позиции и CPU; тактический поиск может быть неглубоким. Нет гарантии силы или отсутствия зевков. Сетевые и ОС-задержки требуют запаса времени. Современный Stockfish существенно сильнее; он не используется и не запускается этим пакетом.

`chess==1.11.2` — [библиотека правил](https://python-chess.readthedocs.io/en/stable/core.html), распространяется под GPL-3.0+. Её лицензия и авторство сохранены в установленной зависимости; собственные исходники поиска и формулы доступны здесь для изучения. Копирование этого тестового движка не является доказательством авторства турнирной работы: правила допуска определяют организаторы.
