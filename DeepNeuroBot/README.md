# DeepNeuroBot

**Нейросеть, которая меняется через эволюцию.** Отдельный третий движок DeepMove:
DeepMoveBot и DeepSpeedBot сохраняют свои прежние алгоритмы.

Готовы небольшой нейросетевой оценщик, тактический поиск, лига самообучения,
отбор по очкам, скрещивание, мутации, сохранения и коннектор к арене.
**Обученного чемпиона в репозитории нет.** По умолчанию бот использует
воспроизводимую случайную сеть поверх ручной базовой оценки и уже может играть.
Elo и превосходство над другими ботами не заявляются.

## Установка без мусора в системе

Из корня DeepMove, Python 3.10+:

```powershell
python -m venv .venv-bots
.venv-bots/Scripts/python.exe -m pip install -e ./clients/python -e ./DeepNeuroBot -e ./DeepPatternBot
```

На Linux/macOS используй `.venv-bots/bin/python` вместо
`.venv-bots/Scripts/python.exe` во всех командах ниже. Окружение локальное;
оно общее для новых ботов. Нужна только библиотека правил `chess==1.11.2`.
Нет PyTorch, GPU, скачивания весов или внешнего шахматного движка.

Общий [BotKit](../clients/python/README.md) предоставляет поиск и транспорт.
Он не зависит от пакета DeepMoveBot: два исходных движка менять не требуется.

## Подготовить, не тренировать

```powershell
.venv-bots/Scripts/python.exe -m deepneuro_bot init --checkpoint DeepNeuroBot/workspace/league.json --population 8 --seed 42
.venv-bots/Scripts/python.exe -m deepneuro_bot inspect --checkpoint DeepNeuroBot/workspace/league.json
```

`init` только создаёт популяцию: **0 партий, 0 поколений обучения**.
Повторный `init` откажется перезаписывать существующий файл.
Начальный размер — 8 особей; это 112 партий на поколение.
Папка `workspace` исключена из Git. По умолчанию ничего не запускается в фоне.

Проверить один ход без обучения:

```powershell
.venv-bots/Scripts/python.exe -m deepneuro_bot analyze --time 0.3 --seed 42
```

## Как устроен движок

| Слой | Назначение |
| --- | --- |
| 21 признак позиции | Материал, размещение, продвижение, пара слонов, пешечные вертикали и темп |
| Сеть 21 → 12 → 1 | 277 эволюционирующих коэффициентов, `tanh` |
| Ручная оценка + нейросетевой остаток | Сеть корректирует основу максимум на ±250 сантипешек |
| Итеративный alpha-beta и quiescence | Поиск тактики, шахи, превращения, повторения и лимит времени |
| Лига | Каждая пара играет 4 партии: по две каждым цветом |
| Следующее поколение | Элита, турнирный выбор родителей, скрещивание и гауссовы мутации |

Отбор идёт **по результатам партий**, а не по красоте оценки.
Победа — 1, ничья — ½, поражение — 0. Два одинаковых дебюта для обоих цветов
снижают перекос от первого хода. Достигнутый учебный лимит длины партии —
ничья с явной меткой `TRAINING_PLY_LIMIT`, а не выдуманная победа по оценке.
Это локальная тренировочная лига, она не начисляет очки в кубки арены.

## Когда решишь обучать

Следующая команда **запускает вычисления**, сама по себе установка их не запускает:

```powershell
.venv-bots/Scripts/python.exe -m deepneuro_bot train --checkpoint DeepNeuroBot/workspace/league.json --games 32 --generations 1 --max-seconds 60
```

Каждый вызов ограничен количеством партий, поколений и временем.
Та же команда продолжает незавершённую лигу. Отбор начинается только после
полного круга; до этого нет «обученного чемпиона». Настройки поиска фиксируются
при `init`: `--nodes 512`, `--max-plies 160` после дебюта. Для серьёзного обучения
потребуются более длинные партии, больше узлов и отдельная оценка силы.

После полного поколения:

```powershell
.venv-bots/Scripts/python.exe -m deepneuro_bot export --checkpoint DeepNeuroBot/workspace/league.json --model DeepNeuroBot/workspace/champion.json --pgn DeepNeuroBot/workspace/league.pgn
.venv-bots/Scripts/python.exe -m deepneuro_bot analyze --model DeepNeuroBot/workspace/champion.json --time 0.5
```

В чекпойнте хранятся популяция, происхождение, очки, курсор матчей,
состояние генератора случайных чисел и последняя завершённая лига.
Сохранение атомарное после каждой завершённой партии. Прерванная партия
не получает очков и переигрывается; предыдущие результаты не теряются.
Последнее полное поколение можно экспортировать в PGN. Более старые поколения
автоматически не накапливаются: сохраняй нужные экспорты отдельно.
Один файл чекпойнта рассчитан на **один процесс обучения**.

## Подключить к DeepMove

Создай на арене партию с ботом и выпусти ключ своей стороны.

```powershell
.venv-bots/Scripts/python.exe -m deepneuro_bot play --url http://127.0.0.1:3000 --game GAME_UUID --side w --max-think 0.5
```

Ключ вводится скрыто или читается из `DEEPMOVE_BOT_TOKEN`.
Для чемпиона добавь `--model DeepNeuroBot/workspace/champion.json`.
Для HardBullet начни с `--max-think 0.25 --reserve 0.2 --poll 0.1`.
Это стартовые настройки, не гарантия от таймаута: сервер считает также сеть
и опрос. Удалённый адрес требует HTTPS. Ключ не передаётся аргументом команды.
`Ctrl+C` отключает клиента; часы арены продолжают идти.

## Проверки

Из корня, в окружении с установленными пакетами:

```powershell
.venv-bots/Scripts/python.exe -m unittest discover -s DeepNeuroBot/tests -v
```

Проверяются смена цветов, отбор победителя, мутации, продолжение лиги,
реальные короткие самоигры, PGN, незавершённая партия, мат и выигрыш ферзя.
Это проверки корректности, не обучение на силу.
