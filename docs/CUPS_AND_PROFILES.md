# Профили, боты и два кубка

## Локальный вход

Открой `http://127.0.0.1:3000/arena` или `http://localhost:3000/arena`.
Регистрация и вход принимают оба локальных имени на одном порту и протоколе.
Сессии браузера привязаны к имени хоста: после смены `localhost` на `127.0.0.1`
нужно войти снова. Чужие сайты, другой порт и отсутствие `Origin` отклоняются.
Для публикации за прокси установи `APP_ORIGIN` в точный HTTPS-адрес сайта.

## Профиль

В разделе «Мой профиль» редактируются имя, никнейм, организация, город, сайт,
описание и аватар. Никнейм используется для входа и публичной ссылки
`/arena/players/{handle}`. Изменение никнейма не меняет ID участника и его ботов.
Все эти поля публичные; пароль, сессии и ключи никогда не возвращаются.

Изображения PNG/JPEG/WebP до 5 МБ обрезаются браузером до квадрата 128×128.
Сервер повторно декодирует картинку, ограничивает число пикселей, удаляет
метаданные и сохраняет WebP в SQLite. SVG и внешние ссылки не принимаются.
Локальные пользователи обновляются миграцией без удаления партий и аккаунтов.

## Бот и команда

1. Создай команду или вступи по коду капитана.
2. В «Мои боты» зарегистрируй движок, его описание и команду. Можно выступать
   независимо — тогда есть только личный зачёт.
3. У каждого бота постоянный ID. Совпадающие имена разных владельцев не
   объединяются. Переименование сохраняет личные очки.
4. Бота редактирует только его владелец. Указать чужую команду без членства
   нельзя. При выходе из команды будущие выступления ботов становятся личными.

## Зачётная серия

В «Кубки и зачёты» выбери своего бота и контроль времени. Передай сопернику
ссылку на созданную серию и отдельно секретный код приглашения. Соперник входит
своим аккаунтом и принимает вызов своим зарегистрированным ботом. Для зачётной
серии нужны разные владельцы и, если оба бота командные, разные команды.

После принятия создаются **ровно четыре партии** с цветами инициатора
**белые / чёрные / белые / чёрные**. Настройки и состав фиксируются на всю
серию. Партии идут последовательно. Перед каждой оба коннектора отправляют
`ready`; затем идёт обратный отсчёт, по умолчанию 8 секунд. Игровые часы до
старта не идут. Ожидающие следующие партии нельзя запустить раньше предыдущих.

Сдача в зачётной партии, включая сдачу до первого хода, — поражение. Обычные
товарищеские партии до старта по-прежнему можно отменить без результата.

### Очки

- Победа: **1**. Ничья: **0,5**. Поражение: **0**.
- После всех четырёх результатов серия атомарно попадает в оба зачёта.
  Частично сыгранная серия показывает промежуточный счёт, но не даёт очков
  в таблице. Дополнительного очка за победу в серии нет.
- Личный зачёт — сумма очков конкретного ID бота за все завершённые серии.
- Кубок конструкторов — сумма очков выступавших за команду ботов. Команда
  фиксируется при принятии серии; последующий перевод не переносит старые очки.
- Сортировка: очки, затем число побед. При равенстве обоих показателей место
  общее. Название и ID определяют только стабильный порядок строк.
- Тестовые партии, старые демонстрационные матчи и игры людей вне зачёта.
  История не объединяется по похожим названиям движков.
- Номинации независимы от этих двух кубков. Это таблица очков, а не Elo.

## API

Все браузерные POST требуют сессию и `Origin`. Боты используют только ключи.
Ошибки, лимиты, правила ходов и PGN описаны в [BOT_API.md](BOT_API.md).

| Запрос | Назначение |
|---|---|
| `POST /api/arena/profile` | Свой профиль: `name`, `handle`, `bio`, `organization`, `city`, `website`, `avatar` (data URL либо `null`) |
| `GET /api/arena/players/{handle}` | Публичный профиль и его боты |
| `POST /api/arena/bots` | Создать бота: `name`, `description`, `teamId` либо пустая строка |
| `POST /api/arena/bots/{id}` | Изменить своего бота, те же поля |
| `POST /api/arena/series` | Создать: `botId`, `format` (`arena`, `hardbullet`, `rapid`, `blitz`), необязательно `startDelaySeconds` 3–120 |
| `POST /api/arena/series/{id}/join` | Принять: `botId`, `invite` |
| `POST /api/arena/series/{id}/invite` | Создателю до принятия: перевыпустить код, отозвав старый |
| `POST /api/arena/series/{id}/key` | Выпустить/отозвать свой ключ серии; ответ `{token}` показывается один раз |
| `GET /api/arena/series` | Последние 100 публичных серий |
| `GET /api/arena/series/{id}` | Счёт, четыре ссылки, цвета, результаты и `counted` |
| `GET /api/arena/series/{id}/connect` | С Bearer-ключом серии: текущая партия и ключ своей стороны |
| `GET /api/arena/leaderboard` | Оба зачёта по всем завершённым сериям, без ограничения последними 50 партиями |

### Подключение серии

Каждый участник выпускает **свой** ключ после принятия приглашения. Передавай
его в заголовке `Authorization: Bearer ...` только при запросе `connect`:

```json
{
  "status": "playing",
  "counted": false,
  "round": 1,
  "score": {"a": 0, "b": 0},
  "gameId": "UUID",
  "side": "w",
  "token": "GAME_SCOPED_SECRET"
}
```

Для `GET /games/{gameId}`, `ready`, `move`, `resign` действует обычный протокол.
Используй **полученный игровой token**, а не ключ серии. После `finished`
снова запроси `connect`: сервер выберет следующую игру и правильный цвет.
После четвёртой получишь `status: finished`, `gameId: null`, `token: null`.
Перезапуск коннектора продолжает текущую партию. Перевыпуск ключа серии
отзывает предыдущий ключ и его игровые ключи во всех незавершённых партиях.

Готовый пример на стандартной библиотеке Python:

```powershell
python clients/series_bot.py --url http://127.0.0.1:3000 --series SERIES_UUID
# Ключ вводится скрыто. Альтернатива: DEEPMOVE_SERIES_TOKEN в окружении.
```

Пример выбирает случайный легальный ход. Подключи свою математику через callback:

```python
from deepmove_client import DeepMoveSeriesClient

client = DeepMoveSeriesClient(url, series_id, series_secret)
result = client.play(choose_move)  # choose_move(state, budget_seconds) -> UCI
```

Ключ не публикуется в ссылках, PGN, счёте серии или таблицах. Он не позволяет
редактировать профиль, команду, бота или управлять соперником. Игровые ключи
ограничены одной стороной одной партии. Удалённый коннектор требует HTTPS;
HTTP разрешён только для loopback. Сервер авторитетно проверяет ходы и время.
Зачёт пока открыт для принятых участниками серий: перед официальным турниром
организатору следует отдельно утвердить состав и расписание.
