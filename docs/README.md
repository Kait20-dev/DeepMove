# Знакомство с DeepMove

**Твой код делает ход.** DeepMove — открытая платформа хакатона по
программированию и шахматам КАИТ №20. Название отсылает к Deep Blue.

Ты пишешь алгоритм, который выбирает шахматные ходы. Арена предоставляет
позицию, проверяет легальность и время, сохраняет PGN и даёт зрителям
наблюдать за матчем. Твой код выполняется на твоей машине.

## Что уже работает

- Партии бот против бота, человек против бота и человек против человека.
- Серверные часы, ограничения одного хода, отложенный старт и отзыв ключей.
- Зрительский режим без регистрации, анимации с возможностью отключения.
- PGN с часами, повтор и разбор завершённых партий локальным Stockfish.
- Профиль с аватаром и организацией, постоянные карточки ботов и команды.
- Личный зачёт ботов и Кубок конструкторов по сумме очков команды.
- Серии из четырёх последовательных партий: каждый бот дважды играет белыми.

## Форматы игры

| Режим | Время каждому | Добавление | Лимит хода |
| --- | --- | --- | --- |
| Arena | 10 минут | Нет | Боту — 3 секунды |
| HardBullet | 15 секунд | Нет | Всем — 1 секунда |
| Рапид | 10 минут | Нет | Только общий запас |
| Блиц | 3 минуты | 2 секунды | Только общий запас |
| Свой формат | 30–7200 секунд | 0–60 секунд | Настраивается |

Три секунды в Arena — ограничение, а не добавление. В HardBullet действует
минимум из остатка общих часов и секунды на текущий ход.

## Два движка для изучения

**[DeepMoveBot](../DeepMoveBot/README.md)** — математический Python-движок:
alpha-beta, итеративное углубление, ручная оценка и контролируемая случайность.

**[DeepSpeedBot](../DeepSpeedBot/README.md)** — C++20-движок со своими правилами,
bitboards, PVS, LMR и предварительным поиском на ходу соперника.

Их сила не измерена в Elo. Изучай подходы, проверяй гипотезы и сравнивай
воспроизводимые результаты. Stockfish используется отдельно, для анализа
после партии.
