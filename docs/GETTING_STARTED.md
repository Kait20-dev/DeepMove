# Быстрый старт

От клонирования репозитория до первого матча. Публичный сайт знакомит с
проектом; сама арена запускается локально или на сервере организатора.

## Требования

| Инструмент | Зачем нужен |
| --- | --- |
| Node.js 24+ и npm | Сервер, встроенный SQLite и сборка |
| Git | Получить исходники |
| Python 3.10+ | Пример коннектора; самой арене не требуется |

Компилятор C++ нужен только при сборке DeepSpeedBot из исходников.

## 1. Запусти арену

```sh
git clone https://github.com/Kait20-dev/DeepMove.git
cd DeepMove
npm ci
npm run dev
```

Открой **http://127.0.0.1:3000/arena**. Сервер доступен только на локальной
машине. Для сетевого доступа прочитай [инструкцию развёртывания](DEPLOYMENT.md).

База `data/deepmove.sqlite` создаётся автоматически. Не удаляй её, если
нужны существующие аккаунты, партии и результаты.

## 2. Подготовь партию

1. Создай аккаунт на арене. Пароль — не менее 10 символов.
2. При желании заполни профиль и зарегистрируй движок в «Мои боты».
3. Создай новую партию: своё место и место соперника укажи как «Бот».
4. Передай сопернику адрес партии и **отдельный код приглашения**.
5. Соперник входит со своего аккаунта и занимает второе место по коду.
6. Каждый участник выпускает собственный ключ бота на странице партии.

Ссылка даёт только просмотр. Ключ — управление одной стороной одной партии;
он показывается один раз. Перевыпуск отзывает предыдущий ключ.

## 3. Подключи первый алгоритм

Из корня репозитория:

```sh
python clients/example_bot.py --url http://127.0.0.1:3000 --game GAME_UUID --side w
```

Вместо `GAME_UUID` подставь ID из адреса партии. Укажи `--side b`, если
занял место чёрных. Ключ вводится скрыто: он не попадает в историю команд.
Пример работает на стандартной библиотеке Python.

Второй участник запускает свой процесс с собственным ключом. Коннекторы
подтверждают готовность; после этого сервер выдерживает обратный отсчёт.
По умолчанию — 8 секунд, чтобы зрители успели подключиться.

## 4. Замени случайный выбор своей логикой

В `clients/example_bot.py` пример выбирает случайный легальный ход. В
`choose_move(state, budget_seconds)` подключи свой поиск и оценку:

```python
def choose_move(state: dict, budget_seconds: float) -> str:
    position = state["fen"]
    legal_moves = state["legalMoves"]
    # Реализуй собственный поиск с ограничением по времени.
    return my_search(position, legal_moves, budget_seconds)
```

`my_search` здесь — место для твоего алгоритма, не встроенная функция.
Возвращаемый ход — UCI: `e2e4`, `g1f3` или `a7a8q` при превращении.
Пример учебный; сила случайного выбора не подходит для соревнования.

Бюджет уже оставляет запас на транспорт. Сам алгоритм должен соблюдать
его: сервер не ждёт завершения твоего процесса и не принимает клиентские
метки времени.

## 5. Посмотри результат

Открой ссылку на партию в другой вкладке: зрителям аккаунт не нужен.
После окончания доступны PGN, перемотка с часами и анализ. Stockfish
запускается только после партии на той же машине, что и сервер.

Для очень быстрых матчей выключи анимации на доске — она будет сразу
показывать последнюю полученную позицию.

## Зачётная серия

В «Кубки и зачёты» выбери зарегистрированного бота, создай серию и передай
сопернику приглашение. После принятия каждый участник выпускает **ключ
серии**, который отличается от ключа отдельной партии.

```sh
python clients/series_bot.py --url http://127.0.0.1:3000 --series SERIES_UUID
```

Коннектор автоматически проходит четыре игры и меняет цвет. Итоговые очки
появятся в таблицах после всей серии: победа 1, ничья 0,5, поражение 0.
Подробности — [профили и два кубка](CUPS_AND_PROFILES.md).

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Ошибка SQLite при запуске | Выполни `node --version`: нужен Node.js 24+ |
| После смены localhost на 127.0.0.1 исчез вход | Сессии привязаны к имени хоста; войди снова |
| Запрос с другого сайта запрещён | Для локальной работы один протокол и порт; для сервера точный `APP_ORIGIN` |
| 403 при ходе бота | Правильные ли ключ, партия и сторона? Не перепутан ли ключ серии с игровым? |
| Партия ожидает | Оба места заняты? Оба коннектора отправили ready? |
| Бот проиграл, хотя общие часы не пусты | Мог истечь отдельный лимит хода; причина и опоздание показаны в партии |
| Нет партий на GitHub Pages | Это статический сайт; запусти сервер арены отдельно |
