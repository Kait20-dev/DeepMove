# DeepPatternBot

**Опыт сыгранных партий + обучаемая оценка.** Четвёртый самостоятельный
движок DeepMove. Он читает локальные PGN по одной партии, индексирует позиции
в SQLite, собирает результаты ходов и обучает лёгкую модель для незнакомых позиций.
Базы партий и обученных весов в репозитории нет; большие файлы не скачиваются.

## Установка

Из корня DeepMove, Python 3.10+:

```powershell
python -m venv .venv-bots
.venv-bots/Scripts/python.exe -m pip install -e ./clients/python -e ./DeepNeuroBot -e ./DeepPatternBot
```

Linux/macOS: `.venv-bots/bin/python`. Окружение можно использовать общее
с DeepNeuroBot. Единственная внешняя runtime-зависимость — `chess==1.11.2`.
SQLite, обучение и вычисления работают локально без GPU и ML-фреймворков.
[BotKit](../clients/python/README.md) содержит общий поиск, признаки и транспорт;
DeepMoveBot и DeepSpeedBot остаются без изменений.

## Подготовить без загрузок и обучения

```powershell
.venv-bots/Scripts/python.exe -m deeppattern_bot init --db DeepPatternBot/workspace/patterns.sqlite
.venv-bots/Scripts/python.exe -m deeppattern_bot stats --db DeepPatternBot/workspace/patterns.sqlite
.venv-bots/Scripts/python.exe -m deeppattern_bot analyze --time 0.3
```

Пустая база создаётся за один вызов. Без базы и весов бот использует поиск
и ручную оценку: он может играть уже сейчас. Импорт и обучение — отдельные
явные команды, не побочный эффект запуска. `workspace` исключён из Git.

## Подготовленный конвейер

| Этап | Что происходит |
| --- | --- |
| Импорт | Потоковое чтение PGN, проверка легальности и результата |
| Индекс | Нормализованная позиция → UCI, победы/ничьи/поражения ходившей стороны |
| Разделение данных | Примерно 80% партий для обучения, 20% для проверки |
| Обучение | Потоковый SGD: прогноз результата партии из 21 признака и базовой оценки |
| Игра | Поиск + статистический выбор только среди близких по оценке ходов |

Проверочные партии **не попадают в статистику ходов**. Данные делятся целыми
партиями, а не соседними позициями одной партии. Точный повтор партии не
накручивает статистику даже из другого файла; конфликтующий результат отклоняется.

## Небольшой пример импорта

Этот пример обрабатывает только четыре написанные для проекта учебные партии:

```powershell
.venv-bots/Scripts/python.exe -m deeppattern_bot import-pgn DeepPatternBot/examples/tiny.pgn --db DeepPatternBot/workspace/patterns.sqlite --max-games 4
.venv-bots/Scripts/python.exe -m deeppattern_bot stats --db DeepPatternBot/workspace/patterns.sqlite
```

Это фикстура для проверки программы, **не качественный тренировочный корпус**.
По умолчанию для хода нужны минимум 3 наблюдения, поэтому на четырёх партиях
большинство ходов будет выбрано поиском.

Для будущего корпуса используй тот же `import-pgn PATH --db PATH`.
Один вызов читает до `--max-games 1000`, принимает партии до `--max-plies 600`,
ограничивает основную БД через `--max-db-mb 256`. WAL и служебные файлы требуют
дополнительного места. После достижения предела вызывай команду повторно —
она продолжит с сохранённого места. Источник должен оставаться неизменным.

Поддерживается обычный несжатый UTF-8 PGN, в том числе BOM. Распаковывать
архивы нужно отдельно. Нестандартные варианты, незавершённые, пустые,
слишком длинные партии и противоречащий финальной позиции результат отклоняются.
Читается основная линия; комментарии и побочные варианты не являются данными обучения.
Парсер ограничивает размер одной партии 2 МБ и останавливает импорт при превышении.
За один раз в памяти находится одна партия; весь корпус не загружается в RAM.

## Обучение — когда понадобится

Команда ниже **явно запускает** ограниченный проход по обучающим позициям:

```powershell
.venv-bots/Scripts/python.exe -m deeppattern_bot train --db DeepPatternBot/workspace/patterns.sqlite --model DeepPatternBot/workspace/model.json --epochs 1 --max-samples 100000 --max-seconds 60
```

Сохраняются веса, номер эпохи, курсор позиции, число обновлений, настройки
и отпечаток состава корпуса. Повторный вызов продолжает обучение.
Чекпойнт записывается атомарно каждые 256 позиций и при нормальном завершении.
После аварии может потребоваться повторить до 255 позиций от последнего сохранения.
Запускай только один тренер на файл модели.

После пополнения базы используй **новый путь модели**: продолжение с изменённым
корпусом запрещено, чтобы проверочная выборка и сравнение оставались понятными.
Метрики содержат cross-entropy модели и исходной ручной оценки на отложенных
партиях, максимум 10000 позиций. Если проверочных партий нет, выводится `null`,
а не придуманная точность. Число эпох и улучшение ошибки не являются Elo.

```powershell
.venv-bots/Scripts/python.exe -m deeppattern_bot analyze --db DeepPatternBot/workspace/patterns.sqlite --model DeepPatternBot/workspace/model.json --time 0.5
```

Ответ показывает `source: search` либо `pattern+search`, найденные ходы,
число наблюдений, оценку и завершённую глубину. Обучение не требуется для
работы самого статистического индекса.

## Подключение к арене

```powershell
.venv-bots/Scripts/python.exe -m deeppattern_bot play --url http://127.0.0.1:3000 --game GAME_UUID --side b --db DeepPatternBot/workspace/patterns.sqlite --max-think 0.5
```

Ключ вводится скрыто или берётся из `DEEPMOVE_BOT_TOKEN`. База открывается
только на чтение. `--db` и `--model` можно не указывать для холодного старта.
Для HardBullet попробуй `--max-think 0.25 --reserve 0.2 --poll 0.1`.
Сеть и серверные часы всё равно влияют на результат. HTTPS обязателен удалённо.
Готовый [коннектор](../clients/python/README.md) проверяет историю и дедлайны;
[API](../docs/BOT_API.md) остаётся единым для всех четырёх движков.

## Проверки и дальнейшее развитие

```powershell
.venv-bots/Scripts/python.exe -m unittest discover -s DeepPatternBot/tests -v
```

Проверяются дедупликация, продолжение импорта, отбраковка PGN, цвета результата,
рокировки/en passant в ключе, отложенная выборка, обучение, продолжение SGD,
смена корпуса, тактика и легальный ход при нулевом времени.

Текущая архитектура — CPU-прототип для подготовки будущего корпуса,
не кластерный сервис для терабайтов. Массовый импорт потребует отдельного
замера места/скорости, очистки источников, качества и лицензий данных.
Историческая частота хода не доказывает его объективную силу.
Подробнее: [математика и ограничения](docs/FORMULAS.md).
